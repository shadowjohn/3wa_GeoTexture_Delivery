# 共享圖集、區塊預覽與車站淨空

## 使用方式

登入圖台後可選「新北市／臺中市」。臺中可直接定位大慶、九張犁、九德、烏日、高鐵臺中站。來源均以 SQLite 唯讀開啟，臺中直接使用既有 `uploads/8/8.db`，沒有複製資料庫。

「合併街廓預覽」使用已完成、相同風格的模型。後台以 256m Web Mercator 格網、每組最多 32 棟產生圖集；桌面最多 8 組、手機 4 組，共用既有 4／2 個下載名額。區塊載入成功後才替換個別模型；未完成、失敗或視野邊界成員不全時保留原預覽。傾斜視角用實際相機中心排序，避免遠方 bbox 中心搶走近處名額。

在「成果匯出」重新框選，按「建立整區 GLB」，等待 AJAX 進度完成後下載 GLB 或 ZIP。原單棟 ZIP 仍保留。新 ZIP 包含 `scene/whole_block.glb`、`scene/manifest.json`、原單棟 `models/*.glb`、建物與框選 GeoJSON、完成／缺漏清單。建立匯出時凍結建物與資產版本，之後新增的成果不會混入舊快照。逐面資料仍保存在原單棟 GLB 的 geotexture extras；合併匯出的清單只保存模型摘要以限制記憶體。

整區 GLB 的每棟建物各有獨立 mesh/node，名稱為 `build_id`，extras 保留 `source_key`、`build_id`、`asset_id`、來源 hash、風格與幾何修正。節點使用原建物局部座標與明確 translation/scale，方便在 glTF 編輯器中單獨刪除、修改、替換；圖集與材質共用。圖台沒有新增建模編輯器。

道路開口內底面 6m，其餘落地，屋頂維持官方高度，補上挑空底面與低側牆。開口與來源輪廓先以 1mm 精度網格做布林運算，避免浮點碎片在 GLB float32 精度下變成零面積；斜向外牆使用相容的 2mm 邊界容差，避免被誤判成內部切面。未修正的普通建物仍通過原本逐面位元等價測試。

`base_m` 可逐棟調整淨空高度，`geometry` 明確保存開口邊界與寬度；`width_scale` 是以開口整體中心做水平比例調整，預設 1，精確調整各條道路寬度應編修 polygon。資料改動會改變 source_hash，舊的實心或舊開口資產不會被重用；既有成果保留，需要建立新任務產生新版本。這些均為**示意淨空，非實測或工程淨高**。

## 限制與佇列

目前合併支援三種 procedural 風格，最多 2,000 棟、20km、200萬輸出三角形、256MiB GLB；無模型、超限或格式不符會明確失敗。預覽貼圖 128px、匯出 512px，圖集邊長最多 4096，2px 重複紋理邊框、linear/clamp，沒有 mipmap。UV 跨重複邊界時會切分三角形，防止取到別棟的圖塊。

沿用每分鐘 cron 與同一 worker flock。每輪最多處理 8 個場景，開始新場景的預算為最多 15 秒且不超過本輪一半，保留時間給原建物轉換；單一場景 Python 上限 90 秒。工作進度只在成果驗證、ZIP 寫入和原子發佈後才到 100%。最多 100 個 queued/running 場景，建立、重試、逾時重排皆在同一 SQLite transaction 內受限。預覽排隊 15 分鐘失效後可再次請求。

新 API 沿用登入、CSRF、關閉 session 後工作、私有快取與 SHA 驗證。下載時也檢查凍結來源版本，沒有接收 HTTP 任意檔案路徑。取消中的子程序會被終止並回收；中斷的 running 工作只在取得 worker lock 後恢復。

## 驗證與測量

100 棟規則形狀測試樣本，Three.js 178、Chromium headless SwiftShader，固定相機，10 次同步 render 平均（不是使用者硬體 FPS 保證）：

| 項目 | 原單棟 | 合批預覽 | 可編修整區匯出 |
| --- | ---: | ---: | ---: |
| 繪製批次 | 300 | 3 | 300 |
| 紋理數 | 200 | 1 | 5 |
| 貼圖像素 | 52,428,800 | 3,659,040 | 53,251,200 |
| 三角形 | 1,200 | 14,200 | 14,200 |
| GLB bytes | 1,778,828 | 2,525,692 | 2,673,160 |
| 平均 render ms | 13.44 | 0.38 | 6.54 |
| 本機首次載入 ms | 3,261 | 4,050 | 1,909 |

預覽貼圖像素減少約 93%，但檔案因 UV 分割而變大；共享圖集改善繪製成本，不能宣稱每種場景首次載入都更快。整區匯出保留獨立建物，因此沒有壓成 3 個繪製批次。所有版本的世界座標 bounds 相符。

七棟實際車站資料均已通過生成及 PHP 正式登錄驗證；獨立合併 GLB 含 7 nodes、21 primitives、1 atlas、23,898 triangles。檢查斜向外牆仍到原屋頂，開口底面為 6m，來源資料庫保持唯讀。

測試包含 PHP 任務／來源／場景快照／缺漏／逾時重排／容量／取消子程序／完整性，Python UV 邊界／圖集像素／舊 GLB 相容／尺寸限制／車站幾何，以及 HTTP 登入、CSRF、304 仍需驗證、ZIP/GLB 下載。Node 測試涵蓋區塊 readiness、失敗回退、版本切換、2D、來源切換、背景輪詢與取消競態。
