# 平移、縮放與區塊邊界預覽改善

這輪實作使用者選定的兩項：保留視野附近已載入模型，以及穩定區塊邊界切換。沒有重製 GLB、增加 LOD、修改 E8 SDK 或新增套件。

## 行為與上限

原有可見模型與下載上限不變：桌面 64 個單棟、8 個區塊、4 個傳輸；手機 24／4／2。額外只保留已 ready 的實際 dgModel instance，不預先下載。視野四側留 25% 緩衝，每側限制在 256–1024 Web Mercator 公尺；臺灣地面距離會因緯度略小。離開緩衝範圍、版本失效或超過預算時釋放。

| 額外保留預算 | 桌面 | 手機（圖台寬小於 600px） |
| --- | ---: | ---: |
| 單棟上限 | 32 | 12 |
| 區塊上限 | 4 | 2 |
| 合計估算記憶體 | 64 MiB | 24 MiB |

依最近使用、距離挑選保留對象；未知貼圖尺寸的舊模型不額外保留。`resident_bytes` 是根據既有幾何／貼圖中繼資料估計的預算值，並非整個頁面或 GPU 實際配置的硬上限。可見模型及既有上限內的傳輸另計。

區塊回應新增完整 `member_versions`（來源、build_id、source_hash、風格、asset_id、位置），所以只看到部分成員仍可顯示整個有效區塊。保留的區塊與單棟會核對已知版本；缺少模型或 hash／asset 不同即撤掉舊區塊。版本觀察僅保留當前建物、區塊與常駐模型所引用的身分，避免無限成長。

完整格網查詢可以更新成員版本；單純的進度輪詢只描述原凍結快照，不可覆蓋之後已觀察到的新版本。新區塊尚未 ready 或失敗時，保留仍有效的舊區塊；ready 後同一輪撤掉重疊的舊區塊與單棟，並立即更新白模遮蔽。E8 dgModel 沒有公開 visibility setter，因此已被區塊取代的單棟直接釋放，不另寫 SDK 隱藏快取。

城市／風格切換、2D、縮小到建物查詢門檻以下會清除保留模型。舊請求完成時仍受原本的版本與下載名額保護，不會重新顯示被清除的模型。

## 實際瀏覽器比較

使用既有隔離帳號與新北已完成貼皮樣本，Chromium、1440×1000、headless SwiftShader、真實 E8。A 為 `[121.4225,25.179]`、zoom 18；B 為 `[121.4235,25.179]`、zoom 18；Z 為 B、zoom 18.8；pitch 55、bearing 0。A→B 約 101m，跨越 256m 格網，Z 裁掉部分區塊成員。暖載入後跑 A→B→Z→A→B→Z→A，兩版本相機與 bbox 完全一致。

| 指標 | 原版 | 改善版 |
| --- | ---: | ---: |
| 路線中的 dgModel 建立次數 | 152 | 0 |
| dgModel 移除次數 | 152 | 1 |
| GLB HTTP 請求 | 141 | 0 |
| 常駐模型峰值 | 64 | 10 |
| Z 穩定後的區塊數 | 1 | 7 |
| Z 取樣最低可見完成覆蓋 | 10／64 | 64／64 |
| 重疊建物取樣 | 0 | 0 |

改版後額外四輪 B→Z→A，275 次取樣皆完整覆蓋且無重疊，沒有新增、移除模型或 GLB 請求。每次回到 A 均為 9 個模型、39 個 geometry、11 張 texture、3 個 shader program，沒有逐輪累積；額外保留預算最大約 10.09 MiB。

瀏覽器攔截測試 JS 以記錄公開的模型增刪與 renderer counters，兩版都因此停用 HTTP cache，所以請求數代表相同條件下的載入嘗試，不是一般使用者的實際傳輸量。這是暖載入路線證據，不代表首次載入或所有硬體的 FPS 改善幅度。手機尚未實機測量。

## 驗證

Node 覆蓋來回移動 instance 重用、保留範圍與數量／估算位元組淘汰、未知成本、視野邊界、重疊換組、新舊版本／缺模型、晚到請求、2D／來源／風格重置與輪詢新舊版本優先序。PHP app 121 checks、auth 30 checks、scene queue／snapshot／cancel／integrity、station-source 及 HTTP 4 tests 通過。

瀏覽器實際操作驗證切換風格、臺中／新北、2D／3D、關閉／開啟合併預覽；2D 後模型、描述資料、GPU geometry／texture／program 均清空，恢復 3D 後覆蓋正常。來源檔案、既有匯出 ID、原 worker 與排程維持相容；新增記憶體估算不參與匯出 fingerprint。
